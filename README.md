# ♕ Seinna Planner

> Rêve • Organise • Brille ♥

Une application de planning douce, rose et inspirante, créée avec amour pour Seinna.

## Aperçu

Application web simple (HTML + CSS + JavaScript) reprenant l'univers rose, les chats noirs, les nœuds et l'esprit bienveillant du planner original.

## Fonctionnalités

- Calendrier interactif
- Planning journalier
- Liste de tâches (To-Do)
- Suivi des habitudes
- Notes
- Santé (cycle, poids, sommeil)
- Self-care
- Objectifs
- Budget
- Suivi d'humeur (Mood)

## Comment l'utiliser

1. Clone le repo :
```bash
git clone https://github.com/housseinaconde2022-hub/seinna-planner.git
```

2. Ouvre simplement `index.html` dans ton navigateur.

Ou utilise un serveur local :
```bash
npx serve .
```

## Structure

- `index.html` — Structure de l'application
- `style.css` — Tout le style rose et doux
- `script.js` — Interactivité (calendrier + planning)
